Plonkit Data API

This website provides JSONs generated automatically from the Plonkit website. Each country has its own JSON, and there is a main file with all countries.

Available Files:

  • all_countries.json — Complete list of countries
  • countries/botswana.json — Individual JSON per country
  • Other countries follow the same pattern in data/countries/

Data Updates

The files are updated whenever the Python crawler runs and generates new JSONs.
