Plonkit Data API

Este projeto fornece JSONs gerados automaticamente do site Plonkit. Cada país tem seu próprio JSON, e há um arquivo principal com todos os países.

Arquivos disponíveis:

  • all_countries.json — Lista completa de países
  • countries/botswana.json — JSON individual por país
  • Outros países seguem o mesmo padrão em data/countries/

Como usar no React Native:


const response = await fetch("https://ingridakeida.github.io/plonkit-data-api/data/all_countries.json");
const data = await response.json();
console.log(data.countries);

Atualização dos dados

Os arquivos são atualizados sempre que o crawler Python roda e gera novos JSONs.
